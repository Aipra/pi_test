## 坦克大战 TANK BATTLE（红白机风格复刻）

文件：`tank-battle.html` —— 单文件、零依赖、离线可玩，双击用浏览器打开即可。

### 操作

| 按键 | 作用 |
|------|------|
| `↑ ↓ ← →` | 1P 移动 |
| `空格` / `J` | 1P 开炮 |
| `W A S D` | 2P 移动 |
| `F` | 2P 开炮 |
| `Enter` | 开始 / 确认 / 下一关 |
| `P` / `Esc` | 暂停 |
| `M` | 静音 |

手机端会自动显示虚拟方向键与开炮键。

### 还原的经典要素

- **战场**：256×224 逻辑分辨率、13×13 格（16px）战场、8px 半格对齐的坦克移动
- **砖墙可打碎半格**：一发子弹打掉 2 格宽（8px×2），与原版一致
- **四种敌军**：普通(100分) / 快速(200分) / 火力(300分) / 重甲(400分，需 4 发，掉血变色)
- **老鹰基地**：砖墙包围，基地被毁即 GAME OVER（自己的炮弹也能打掉，原版如此）
- **奖励坦克**：每 4 台敌军中有一台闪烁，击毁掉落道具
- **六种道具**：★升级、手雷清场、头盔护盾、铲子（基地外墙变钢）、坦克加命、时钟冻结
- **地形**：砖 / 钢 / 树（覆盖在坦克之上）/ 水（坦克不可过、子弹可过）/ 冰（会打滑）
- **其他**：出生闪烁动画、护盾光圈、爆炸帧动画、STAGE 过关结算画面（按敌军种类计分）
- **音效**：WebAudio 合成的 8-bit 方波/噪声音效，无任何音频文件

### 5 个关卡

砖墙阵 → 树林 → 水与钢 → 冰面迷阵 → 混合终关，循环进行，敌军强度随关卡上升。
